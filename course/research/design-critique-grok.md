先對齊現況與提案，並查當代醫學教育站的視覺參照，再給有主見的藝術方向評審。提案是設計評審不是實作。先摸清現有視覺系統，再對照當代醫學教育站。找到膝部課程站了。接著讀現有 token／設計升級文件，並對照當代醫學教育站的實際視覺。這份提案**臨床判斷是對的，藝術方向是平庸的安全牌**。它把現站真正的病（Primer 套 GE LOGIQ 皮、teal 當牆紙、格線與 glow 跟影像搶視線）治好了一半，卻把身分換成 2024–2026 醫學教育 SaaS 的標準配備。醫師會覺得「專業了」；設計師會覺得「哪裡都見過」。

當代參照很清楚：Radiology Assistant 幾乎沒有 chrome，品牌是黃箭頭與線稿圖譜；Radiopaedia 是反設計，病例圖就是介面；AMBOSS 把 overlay 做成產品功能，文字裡綠珍珠／紅警示分色；真正的超音波主機才用黑畫布＋黃卡尺＋青 Doppler。你們現在的深藍 teal 工作站，是在抄**儀器**，不是在做**教學站**。提案從儀器走向「暖紙＋黑燈箱」，方向對，但還停在「正確的家具」，沒走到「認得出來的手」。

## A. 對提案的批判

### 哪裡對

**雙材質是這份提案唯一的結構性正確。** 閱片室要控光，教科書要紙白——這不是風格，是 ACR 電子影像實務與醫師作息的同一件事。影像畫布永遠中性黑、不隨主題反相，這條必須寫死。現站 `clinical.css` 把全頁 32px 格線、teal glow、command bar 掃描感當品牌，等於讓裝飾跟聲窗搶對比；把 teal 從「品牌牆紙」收成互動色，是在修一個真的錯。

測量值／時間戳 mono 化也對。診斷畫面裡的 `TE`、`TR`、`12.4 mm`、`00:13` 是資料，不是文案；tabular nums 比任何襯線標題都更能讓人覺得這是工作站。

動效只留診斷語意——大方向對。現站已經有「科幻工作站」過剩的診斷（`DESIGN_UPGRADE` A2／A8），再堆常駐 pulse 是自傷。

### 哪裡是平庸安全牌

**1. Noto Serif TC 當標題，是台灣學術／市政網站的預設配對，不是權威。**  
Noto Sans TC + Noto Serif TC 是 Google Fonts 的 CJK 套餐，政府標案、博物館、醫學會官網都這樣走。襯線在這裡被拿來「買教科書感」，但你們的雙材質**已經**用紙面 vs 燈箱表達教科書 vs 工作站。再疊一層明朝體，是兩套權威訊號互踩。Bold 的 Noto Serif TC 在 28–32px 會顯肥、顯「報告封面」，不是肌骨圖譜。

**2. 「暖白紙面」很容易做成 SPA／健康品牌的奶油白。**  
提案寫「暖」，執行端一定會走到 `#FFF8F0`、微黃、柔圓角。那是診所官網，不是銅版紙期刊。NEJM／圖譜要的是**乾的紙**，不是溫暖。

**3. Teal 收斂但仍當主互動色，等於承認 2019 health-tech 色盤。**  
One Medical、Teladoc、無數「臨床儀表板」都是這個青。醫師看多了會自動歸類成「又一個健康 SaaS」。互動色應該低調到近乎外科縫線；真正准許發亮的，是疊在灰階影像上的標註，不是按鈕。

**4. 琥珀同時管「教學標記」與「陷阱」，語意撞車。**  
Primer 的 attention 本來就是琥珀。教學箭頭（看這裡）和陷阱（別認成這個）若同色，quiz 一開標註，學生分不清「重點」和「假象」。Radiology Assistant 的黃是**單一、偏執、可被記住的教學色**；AMBOSS 則把珍珠與警示拆成綠／紅。你們把兩種教學行為塞進同一管琥珀，是語意懶惰。

**5. 「約 20 個 pictogram 取代 Lucide」是設計系統工作坊的標準產出。**  
Lucide 負責搜尋、選單、播放，不該被取代。探頭位置、照射位、MRI 切面不是 icon，是**圖譜線稿**。20 個對 UI 太多、對膝部標準聲窗太少（髕上長軸、內側關節線、MCL、鵝足、LCL、膕窩、Baker……遠超過 20）。畫成 24×24 的「小符號」，醫師看不出探頭長／短軸，就只是一組比較貴的 emoji。

**6. 載入掃描線是現站科幻皮的殘骸，不是診斷語意。**  
B-mode 的掃描線是儀器物理；網頁 skeleton 上跑一條掃描線，是 HUD 迷因。提案一邊說殺掉裝飾動效，一邊把掃描線留成「有醫學意味的 loading」，這是自我矛盾。

### 哪裡有執行風險

| 風險 | 為什麼會爆 |
|---|---|
| 紙面／燈箱接縫 | 捲動從暖紙進純黑，OLED 上會閃；焦點環、tooltip、側欄若跨兩套表面，會出現兩種 teal。必須有**接縫規則**，不是兩套 token 並置。 |
| 純黑 `#000` 壓死近場 | 超音波近場與 MRI 脂肪是近黑灰。畫布要用能保住 8-bit 暗部的中性黑（約 `#0C0E12`），不是廣告片的純黑。 |
| Overlay 不跟模態走 | 琥珀在 B-mode 上漂亮；在彩 Doppler 上跟血流撞色；在 X 光上可能對比不足。標註色必須通過「灰階／Doppler／X 光」三關，不能只在 Figma 的假超音波上過。 |
| CJK 襯線網頁字重 | Noto Serif TC 全套極重。若只為標題載入、再加 Bold，首屏會為一個「看起來很教科書」的決定付字體稅。 |
| Pictogram 解剖正確性 | 左右側、探頭標記（notch）、長／短軸、MRI 矢狀／冠狀／軸狀，畫錯就是教學錯誤，不是美工錯誤。這是插畫＋醫療審閱，不是 icon sprint。 |
| 雙主題 + 雙表面 | 現有 `data-theme` 已經一套；再加 paper/canvas，組合爆炸。列印、OG 圖、quiz 回饋色都要各定一條，否則暗色模式會把紙面「溫暖」弄髒。 |

一句話：提案是**好的設計系統清單，不是藝術方向**。它回答「怎麼變得專業」，沒回答「截圖一張，為什麼認得出是你們」。

## B. 替代／強化：燈箱圖譜

不要做「暖紙 SaaS + 黑 viewer」。做**把燈箱和中文圖譜攤在同一張桌上**。Chrome 退到幾乎沒有；認得出來的是標註文法，以及每張圖角落那枚探頭／切面線稿。

**Hero 一句話：**  
一張已標註的膝部聲窗佔滿燈箱，左下角鎖死一枚探頭位置線稿，說明文字印在旁邊的銅版紙上——不是儀表板，是閱片燈箱加一本攤開的圖譜。

### 色票（六色，角色互斥）

| 角色 | Hex | 用法 |
|---|---|---|
| 紙面 | `#F2EFE6` | 閱讀層。乾的銅版紙，不是奶油 SPA。 |
| 墨色 | `#1A2330` | 正文與標題。冷墨，告別現站 `#08283d` 那種儀表板海軍藍。 |
| 燈箱 | `#0C0E12` | 影像永遠待在這。不反相、不跟主題走。 |
| 教學標記 | `#E0B000` | **只**給目標結構：實線箭頭、卡尺、ROI 外框。這是你們的黃——向 Radiology Assistant 學偏執，不要學它的版面。 |
| 陷阱 | `#C43B6E` | 虛線／斜線填充。假象、正常變異、勿過度診斷。與教學黃分開，quiz 才讀得懂。 |
| 互動 | `#1B6B73` | 按鈕、焦點、目前單元。去飽和，讓路給標註。 |

禁忌另用 `#B42318`，只給 MRI 安全、輻射正當性、絕對不要做的事。進度／已掌握用墨色＋一條細進度，不要再發明第四種青。

紙面上的互動色與燈箱上的互動色是**同一色相、兩套亮度**，先在真實影像上校准，再寫進 token。不要讓 Figma 的 `#1B6B73` 直接鋪到黑畫布上。

### 字體配對

- **正文／UI：** `Noto Sans TC` 400／500／700。維持現況，16px／行高 1.7，欄寬 68–76ch。這是對的，不要換。
- **標題：不要上 Noto Serif TC Bold。** 權威來自層級與留白，不是明朝體。單元名用 Noto Sans TC 500、字號跳到 32–40px，英文縮寫（`PDW`、`MCL`、`TE`）微縮、字距略開。
- **若一定要襯線：** 只用 `Noto Serif TC ExtraLight／Light`（200–300）於**紙面 H1**，從不進燈箱、從不進按鈕、從不用 700。那是圖錄封面，不是每個 `<h2>`。
- **資料：** `IBM Plex Mono`（或現有 `ui-monospace`）專職時間碼、測量、DICOM 標籤、證據等級。這才是「工作站」字體，不是襯線。

### 對提案五件事的改寫

1. **雙材質保留，溫度改乾。** 紙＝`#F2EFE6`，燈箱＝`#0C0E12`。Header 不要再做半透明海軍指揮列；紙面走薄線分隔，燈箱走無框。
2. **黃／洋紅拆開。** 教學 ≠ 陷阱。色盲與「不只靠顏色」：實線 vs 虛線 vs 斜線，標籤文字永遠在。
3. **Pictogram 降成「聲窗線稿」8–12 枚，不取代 Lucide。** 每枚是膝輪廓＋探頭＋切面的 3 筆線稿，出現在影像角與單元目錄， anatomically reviewed。UI chrome 繼續 Lucide。
4. **殺掉掃描線。** 准許的動效只有三個：cine 真的在播、標註在「先看圖」之後淡入、quiz 對錯。跳播不要微光。
5. **身份錨在 overlay，不在字體。** 截一張帶黃箭頭、洋紅陷阱、角落探頭線稿的聲窗，關掉網址列，仍應看得出是這個課。

## C. 最關鍵的一條

**把標註文法做成品牌，其餘當家具。**

雙材質、襯線、pictogram、收斂 teal，全是家具。Radiology Assistant 能醜、能舊、能沒有設計系統，醫師仍認得出那支黃箭頭。你們若只有暖紙加 Noto Serif，做完會是「比較好看的 Primer 課程站」——專業，但不被記住。

先定三條不可破的 overlay 規則（結構＝鎘黃實線、邊界＝同色虛線、陷阱＝洋紅斜線），再畫 8 枚聲窗線稿鎖在每張圖同一角落，最後才動字體與紙色。設計感來自**限制極嚴的教學標記**，不是來自多一個字族。

若只能做一件事：不要導入 Noto Serif TC。把同一週工時拿去定 overlay，並在真實超音波／X 光／MRI 各一張上過對比。紙面漂不漂亮，醫師兩週後不記得；標註一看就懂，才是這個站的臉。
