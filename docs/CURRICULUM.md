# 課程架構

課程以現行專業指引定義的完整診斷掃描流程為骨架，影片只作正常解剖與探頭路徑示範，不反向決定醫療標準。全課為 zh-TW 醫師專業教育，介入操作延後。

## 八單元

1. **課程定位、臨床問題與安全**：完整與聚焦檢查、能力邊界、急慢性影像策略、紅旗及升級決策。
2. **探頭、最佳化與方向標示**：頻率、深度、焦點、增益、各向異性、低流速 Doppler、壓力與永久紀錄。
3. **前側：伸膝機轉與前隱窩**：股四頭肌腱、髕上／髕旁隱窩、滑車軟骨、髕骨支持帶、髕腱與前側滑囊。
4. **內側：MCL、鵝足與半月板周邊**：淺深 MCL、鵝足、半膜肌相關結構及固定條件之外翻動態。
5. **外側與後外側**：髂脛束、LCL、股二頭肌腱、膕肌腱、近端脛腓關節與腓總神經。
6. **後側、囊腫與動態安全**：半膜肌—內側腓腸肌間滑囊、典型 Baker cyst 頸部、膕窩神經血管及後聲窗限制。
7. **常見病理與證據邊界**：肌腱／韌帶、積液／滑膜、滑囊／囊腫、OA 與半月板周邊所見的不確定性和升級條件。
8. **完整掃描、報告與品質回饋**：四區整合、最低影像集、結構化報告、限制語句、督導與結果回饋。

## 跨單元規格

- 前、內、外側多由仰臥開始；前方約屈膝 20–30 度，滑車軟骨改用最大可耐受屈曲；後方以俯臥伸膝為主。
- 相關結構沿全長追蹤，正常與異常皆以兩個正交平面確認；動態與對側比較只提供脈絡，不單獨等同診斷。
- 先用 heel-toe／tilt 排除各向異性；滑囊、淺層液體與低流速 Doppler 使用輕壓並記錄設定。
- 超音波擅長表淺肌腱、韌帶、滑囊、囊腫、周邊神經與即時動態；對完整十字韌帶、深部軟骨、骨髓及複雜半月板病變有限。
- 急性明顯創傷、感染／腫瘤疑慮、鎖膝、伸膝機轉中斷、神經血管缺損或疑 DVT 時，依正式路徑升級，不用陰性局部掃描作全面排除。

## 單元完成定義

每個非導論單元均具至少一筆已驗證來源、兩項以上學習目標、必要視圖、操作重點、陷阱及可觀察評量。所有單元目前維持 `draft`；自動 gate 通過與 draft PR 都不會把單元改成 `medical-review` 或 `approved`。只有具資格且已記名的醫療審閱者可在逐單元簽核後變更狀態。

`core / extension` 只表示影片學習優先級，不能取代證據等級、來源權威或醫療審閱狀態。
