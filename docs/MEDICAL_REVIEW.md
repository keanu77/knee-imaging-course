# 醫療內容審閱

## 責任與目前狀態

- 內容負責人：吳易澄
- 預定醫療審閱者：吳易澄
- 資格：復健科專科醫師
- 審閱範圍：膝部診斷性肌肉骨骼超音波課程逐單元內容、影像清單、影片範圍、限制與升級條件
- 目前簽核狀態：尚未簽核；8 個單元全部維持 `draft`
- 審閱日期：尚未簽核，故不填日期
- 版本／commit：待 draft PR 建立後由審閱者在實際簽核紀錄中指定

本檔登錄責任人與預定流程，不代表醫療內容已審閱、認可或 `approved`。自動 audit、CI、GitHub PR、影片來源權威或網站可開啟均不構成醫療核准。

## 逐單元審閱項目

- 標準掃描順序、病人姿勢、探頭方向與最低影像集合是否符合現行專業指引及所在地規範。
- 解剖、病理、動態操作、假影、限制、紅旗與升級路徑是否正確且沒有過度確定。
- 聚焦檢查、後膝神經血管、DVT 轉介、十字韌帶與半月板限制是否表達清楚。
- 影片示範是否與課程文字一致；2021 原始內容日期不精確、商業揭露未載等限制是否充分呈現。
- 每項評量是否可觀察、可由合格督導回饋，且不暗示線上完成等於獨立臨床能力。
- diagnostic-only 邊界是否完整：沒有穿刺、注射、處置步驟或劑量建議。

## 狀態規則

- `draft`：內容尚未由具資格醫師逐單元簽核；本版全數在此狀態。
- `medical-review`：來源與內容已整理完成，且已正式送交具名審閱者，但尚未核准。
- `approved`：具資格醫師已對指定版本逐單元記名確認。

只有所有單元均為 `approved`，且醫療審閱者另行明確授權，才可考慮把 `allowIndexing` 改為 `true`。本次授權明確排除醫療核准與開放索引。

## 待人工簽核後補記

醫療審閱者應在未來的獨立審閱變更中記錄：審閱日期、精確 commit、逐單元決定、修改要求、任何例外與 indexing 決策。這些欄位目前保持「尚未簽核」，不由 Codex 代填。
