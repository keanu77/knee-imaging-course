以下路徑相對於 `src/web/`；`seo.py` 相對於 `src/build/`。僅做原始碼分析，未量測瀏覽器效能。

1. **P1｜跳轉連結不可見且目標會隱藏**
`index.html:35`、`css/tokens.css:215`、`js/app.js:667`：跳轉連結聚焦後仍被裁成 1px；首頁／播放器的 `#main` 為 hidden。鍵盤使用者無法可靠跳過導覽。修法：加入聚焦顯示樣式，跳至目前可見內容並移入焦點。

2. **P1｜互動控制巢狀**
`js/render.js:547–550`：button 內放可聚焦的 checkbox span，掌握度與展開控制重疊，造成輔助科技語意衝突。修法：拆成同層的展開按鈕與獨立勾選控制。

3. **P1｜展開狀態未同步**
`js/app.js:838–839,1016–1017`、`js/render.js:593`：章節／單元僅切 class；肌群按鈕永遠宣告 `aria-expanded=false`。讀屏無法判斷內容是否展開。修法：所有展開入口統一同步 expanded、controls 與內容可見性。

4. **P1｜快捷鍵攔截原生操作**
`js/keys.js:119,145–152`：只排除輸入欄，播放器內按鈕的空白鍵被改成播放／暫停；分隔條方向鍵還會冒泡成快轉。修法：排除互動元素、檢查 `defaultPrevented`；字元快捷鍵提供停用／重設。

5. **P1｜快捷鍵視窗缺焦點管理**
`js/keys.js:90–111`：遮罩只切 class，未移入、限制或還原焦點，關閉圖示也無名稱。使用者仍能操作背後內容。修法：改用 `dialog.showModal()`，命名關閉鈕並還原觸發點。

6. **P1｜換片及跨區導覽丟失焦點**
`js/app.js:666–669,735–742,757–766`、`js/player.js:250,286`：隱藏來源或整區替換 HTML，僅捲動而未重新聚焦。鍵盤操作失去接續位置。修法：保留控制節點，或重繪後聚焦對應控制／目標標題。

7. **P1｜窄螢幕換片鈕失去名稱**
`css/player.css:459–463`、`js/player.js:306–307`：≤900px 隱藏唯一文字，剩下隱藏於輔助科技的 SVG。讀屏無法分辨上一部／下一部。修法：按鈕加固定 `aria-label`，或僅視覺隱藏文字。

8. **P1｜手機署名覆寫斷點**
`css/clinical.css:1632–1634,1755,2056–2058`：末端 `display:inline-flex` 覆蓋署名隱藏規則；手機 grid 未配置署名位置，但黏附偏移仍假定標頭113px。修法：將署名基礎樣式移至斷點前；實際裁切程度待瀏覽器驗證。

9. **P2｜篩選與播放狀態僅靠視覺**
`js/app.js:944–947,1053–1058`、`js/filters.js:47–49`、`js/player.js:237`：只切 active／playing class；結果數亦無 live region。讀屏不知選取與結果變化。修法：同步 pressed／current，結果數加 `role=status`。

10. **P1｜單元深連結停在首頁**
`js/app.js:1227–1232,1251–1260`：初訪預設 home，處理單元 hash 時只展開隱藏章節，未切 course。分享連結看不到目標。修法：章節／單元 hash 優先決定分頁，hashchange 也處理這兩類目標。

11. **P2｜章節標題無標題語意**
`js/render.js:555,596`：章節與單元名稱皆為 span，內容卻使用 h3／h4。讀屏標題導覽跳過課程骨架。修法：章節用 h2、單元用 h3 包住展開按鈕，重整子標題層級。

12. **P2｜首次展開重複渲染首頁**
`js/app.js:129–132,369–372,1019–1020`：首次展開經 markLearning 與 rememberUnit，各重建一次 landingBody，即使首頁隱藏。增加不必要 DOM 配置。修法：合併狀態更新，首頁需要顯示時才刷新；耗時待量測。

13. **P2｜拖曳同步強制排版**
`js/player.js:403–405,416`：每次 pointermove 寫欄寬後，fitFrame 立即讀尺寸再寫影片寬度。增加主執行緒排版負擔。修法：以 requestAnimationFrame 合併事件、分離讀寫；卡頓幅度待量測。

14. **P2｜正文完全依賴 JS**
`index.html:254–258`、`js/app.js:1152,1176–1178`：初始正文只有載入提示，seo.py 未預渲染章節。未執行 JS 的爬蟲讀不到教學正文。修法：Python 建置輸出語意化章節與筆記，再由 JS 增強互動。

15. **P2｜sitemap 修改日期失真**
`seo.py:260`：lastmod 使用建置當日，無內容變更也更新。搜尋引擎取得不可靠的更新訊號。修法：取實際內容修訂日期；無可信日期則省略。
