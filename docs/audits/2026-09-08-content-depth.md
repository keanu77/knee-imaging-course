## 判斷

現有課程足以建立系統性基礎，部分內容已到進階；但不足以證明學員具有獨立專科判讀能力。主要差距是複雜病例的比較、影像依據與報告產出、實際掃描及督導回饋，沒有一個固定影片數能補上這些能力。ACGME 的運動醫學里程碑區分知道原理、有指導下取得影像/產生報告、獨立執行，以及可供他人諮詢的層級：[原始里程碑](https://www.acgme.org/globalassets/PDFs/Milestones/SportsMedicineMilestones.pdf)。本課不是該機構認證課程。

實際執行 Codex CLI（預設模型與 CLI 不相容後改 gpt-5.5）、Grok CLI、Antigravity CLI（讀檔被拒後改傳入材料、未改權限）、本機 Qwen 3.8 27B。Qwen 回傳完整結果，prompt_eval_count=70374。分別檢查評量、課程覆蓋、來源透明度、醫療文字；OpenEvidence 用於研究探索，再查 PubMed/Europe PMC、學會與醫師原始頁面。

四模型 29 項原始發現經獨立 Pass 2 全面拆分驗證，主代理再核數字與實際程式。沒有確認 P0；大多數有效缺口是 P1 的學習產出不足。相同批次 hash 被誤判為偽造、來源連結作答前洩漏、Pedret 沒有播放邊界等均剔除。Qwen 提出的八項原始缺陷均未達 0.70；其建議中的 CT 對比劑、magic angle 分類和「證明無相關」等不採用。

完整裁決：[Pass 2](2026-09-08-advanced-multi-llm-validation.md)；原始輸出在 `advanced-llm-raw/`。

另發現既有 `mr3-u1-q2` 的解析把 CT/MRI TT-TG 切點混用的偏差方向寫反。已依本次具體收錄裁決修正題組，原審閱資料保留於新approval ledger；修正為「CT 與 MRI 的量測值及切點不可直接互換，應採用與影像方法及族群相符的判準。」

## 查證與限制

- 七片皆主代理實際取得 yt-dlp metadata 與英文自動字幕，確認 public、playable_in_embed=true；逐段文字核對、選取診斷範圍，排除操作／選術／成本／行銷與不合宜內容。這不是完整逐影格醫學審查。
- 四支 2020 影片有具體經典例外理由；保留日期，不改稱近期錄製。
- 講者資格由本人／機構／學會原始頁核對；PLC 片另含 LaPrade 訪談。2022 解剖研究與片中命名不一致，保留爭議而非捏造一致共識。
- PubMed/Europe PMC 核對 PMID、DOI、年份、研究設計與摘要。神經、PTFJ、Doppler 的研究界限逐項保留；不把個案、屍體或仿體結果當通用閾值。
- 七片真實串流抽查均已通過：目標影片 ID 正確、非廣告、解碼影格和指定起點播放時間持續增加。舊失敗來自 review 病例頁 CSP 禁止 iframe；修正測試環境後成功。證據 `2026-09-08-advanced-playback.json`。此為本機短段抽查，非全片視聽或正式網域驗證。
- 原期刊確認有 Supplemental Video 1/2 圖說與入口，未完成該串流解碼驗收。未下載／重製第三方影像或完整字幕到 repository。
- 尚缺真正未知答案的完整影像包、可重複的標註／量測、現場掃描與專家逐案回饋。仍缺跑者 ITB／股二頭肌腱完整 cine、全面術後半月板對照、完整骨軟骨病變盲測和發炎／感染／腫瘤影像集合。不能稱本批已達「頂尖醫師」能力。
