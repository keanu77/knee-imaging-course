# 膝關節影像醫學教育課程稽核報告

## 1. [P0] ch11-u1-q4
*   **檔案/位置**：`questions.units.ch11-u1.questions[3]` (ch11-u1-q4)
*   **問題**：過度宣稱/醫療背書風險。選項解析或題目語境若隱含將「影像所見」與「臨床症狀來源」直接掛鉤的邏輯，或未嚴格區分描述性報告與臨床診斷權限。雖然正確答案強調了脈絡，但需確認選項設計未暗示學員具備將放射學發現轉化為臨床處方（如手術建議）的能力。
*   **精確證據**：選項 D「建議手術會診」被標記為錯誤，解析為「治療建議超出診斷課程範圍」。此處處理正確，但需確保題目 Stem 本身未诱导學員進行臨床決策推演，僅限於影像判讀。
*   **具體補強**：維持現狀，但建議在題目解析中明確註明：「本課程僅授影像描述與鑑別，不涵蓋臨床手術適應症的決策，此為 credentialing 範圍之外的能力。」以強化能力邊界認知。

## 2. [P1] us-sport-collateral-q1
*   **檔案/位置**：`questions.units.us-sport-collateral.questions[0]` (us-sport-collateral-q1)
*   **問題**：證據等級誤用/過度承諾。題目引用 `REF-BHIMANI-MCL-2022`（屍體研究，8 knees），解析卻將屍體研究的操作變數直接應用於活體門診的「報告記錄」標準，未明確標註屍體與活體在應力測試中的生物力學差異，易導致學員誤以為屍體研究的量化閾值可用於臨床活體診斷。
*   **精確證據**：單元 `us-sport-collateral` 的 `key_points` 已指出「屍體研究的切斷模型...不等於活體...通用分級」，但題目 `us-sport-collateral-q1` 的解析僅強調「操作條件」，未明確警示「切勿套用屍體研究之絕對閾值於活體診斷」。
*   **具體補強**：在選項 B 的解析中增加註腳：「注意：Bhimani 研究為屍體模型，其量測數據僅供參考解剖結構關係，不可作為活體急性損傷的絕對診斷閾值。」

## 3. [P1] us-sport-extensor-q3
*   **檔案/位置**：`questions.units.us-sport-extensor.questions[2]` (us-sport-extensor-q3)
*   **問題**：證據誤讀/過度承諾。引用 `REF-COOK-PATELLAR-2000`（無症狀群體），解析強調「影像異常不等於當下有症狀」，但未明確指出該研究為「無法預測個人預後」，學員可能誤解為影像無臨床價值或可忽略。
*   **精確證據**：`REF-COOK-PATELLAR-2000` 的 metadata 註明 `cannot predict individual outcomes`。題目選項 C 正確，但未在解析中明確連結到「無法預測個人預後」這一關鍵限制，僅泛泛而談「結合症狀」。
*   **具體補強**：修改選項 C 解析，明確加入：「Cook 研究顯示無症狀群體存在結構異常，證明了影像異常與當下症狀的非相關性，但並未提供個人的預後預測，故不可單憑影像排除風險或決定回場時程。」

## 4. [P2] ch8-u1-q1
*   **檔案/位置**：`questions.units.ch8-u1.questions[0]` (ch8-u1-q1)
*   **問題**：繁中用語精確性。選項 A 解析中「年齡 ≥55 本身就是判準之一」，雖符合 Ottawa Rule，但未明確說明 Ottawa Rule 為「排除性檢核表」（Rule-out），學員可能誤用為「篩選表」（Rule-in），導致對特異度低的誤解。
*   **精確證據**：`ch8-u1` 的 `key_points` 提及「高敏感度、中低特異度」。題目解析未呼應此證據特性，僅強調「符合判準」。
*   **具體補強**：在解析中補充：「Ottawa Rule 主要用於高敏感度的『排除』策略，陽性結果因特異度低，仍需臨床上判斷是否需要進一步影像，並非所有陽性者皆為骨折。」

## 5. [P2] ch10-u1-q2
*   **檔案/位置**：`questions.units.ch10-u1.questions[1]` (ch10-u1-q2)
*   **問題**：技術用語精確性。題目涉及「Magic Angle」，解析提及「短 TE＋約 55 度」，但未明確區分這是 T1 或 T2* 等特定序列的特性，學員可能誤以為所有 MRI 序列皆有此問題。
*   **精確證據**：`ch10-u1` 的 `pitfalls` 提及「magic angle...短 TE 序列」。題目解析較簡略。
*   **具體補強**：在解析中註明：「Magic Angle 現象主要發生於 T1 或 T2* 等短 TE/中長 TR 序列，在 PD/FS 等流體敏感序列中表現不同，需依序列類型判斷。」

## 6. [P2] mr3-u1-q2
*   **檔案/位置**：`questions.units.mr3-u1.questions[1]` (mr3-u1-q2)
*   **問題**：數據過度精確化風險。題目涉及 TT-TG 距離，解析提及「MRI 常見研究切點約 13–15 mm」，但未明確警告此數據受族群、序列及切面影響極大，禁止學員在報告中寫死此數值為絕對異常標準。
*   **精確證據**：`mr3-u1` 的 `key_points` 已提及「受序列、切面與族群影響」。題目解析未重申此限制。
*   **具體補強**：在解析中強調：「報告中應記載實測數值與量測方法，不宜僅套用單一文獻切點（如 13-15mm）作為唯一的異常判斷標準，因不同研究間差異顯著。」

## 7. [P2] ch9-u1-q3
*   **檔案/位置**：`questions.units.ch9-u1.questions[2]` (ch9-u1-q3)
*   **問題**：臨床流程過度簡化。題目關於 Lipohemarthrosis，正確答案為「CT 追查」，但解析未提及在特定臨床情境下（如無法平臥、禁忌 CT 對比劑等）MRI 可能是更適切的替代選擇，造成診斷路徑的絕對化。
*   **精確證據**：`ch9-u1` 的 `key_points` 提及「以 CT 追查隱匿性平台骨折」。
*   **具體補強**：在解析中補充註腳：「CT 為隱匿性骨折的常用首選，但需視病人情況（如腎功能、輻射暴露考量）選擇 MRI 作為替代或補充檢查。」

## 8. [P2] ch5-u1-q2
*   **檔案/位置**：`questions.units.ch5-u1.questions[1]` (ch5-u1-q2)
*   **問題**：患者安全風險。題目問後膝腫塊第一步，正確答案為「確認血流」。選項 C「以探頭壓力測試可壓性」被標記為錯誤，解析僅說「壓力會改變外觀」，未明確警示對動脈瘤加壓可能造成的潛在風險（如導致破裂或疼痛），安全警示不足。
*   **精確證據**：`ch5-u1` 的 `pitfalls` 提及「誤把動脈瘤當囊腫」。
*   **具體補強**：在選項 C 解析中增加安全警示：「對疑似血管性病灶（如動脈瘤）施加強力壓迫可能導致疼痛或潛在破裂風險，應先以無壓力或極輕壓進行 Doppler 評估，而非直接測試可壓性。」
